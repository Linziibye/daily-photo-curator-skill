# Photography Curation Rules

## 1. Purpose

This reference defines the complete photography-curation methodology used by `Daily Photo Curator`.

It governs:

- theme selection;
- long-term theme rotation;
- search-language design;
- candidate-pool construction;
- aesthetic-intuition screening;
- strong-candidate reduction;
- cross-platform comparison;
- benchmark-image selection;
- aesthetic-DNA extraction;
- second-round refinement;
- subject consistency;
- creator consistency;
- formal scoring;
- creative and visual-impact thresholds;
- Irreplaceable Point evaluation;
- final 9-image quality control.

This file defines **how to judge and curate photographs**.

Source verification, licensing, original work pages, download links, and final response structure are handled in:

`references/source-and-delivery.md`

File downloading, validation, packaging, ZIP generation, and technical fallback behavior are handled in:

`references/files-and-fallback.md`

---

# 2. Fundamental Curation Principle

The Skill must behave like a curator, not a generic search engine.

The objective is not:

> Find nine technically acceptable photographs.

The objective is:

> Discover broadly, eliminate aggressively, identify a strong visual direction, and keep only photographs that are individually worth saving and collectively form a deliberate series.

The final collection should feel like:

- a small photography exhibition;
- a magazine photography feature;
- a visual research board;
- a mini photo book;
- a professionally curated moodboard.

It should not feel like:

- nine random search results;
- nine generic stock images;
- nine visually unrelated photographs;
- nine similar thumbnails selected because they were easy to find.

---

# 3. Aesthetic-First Rule

Aesthetic judgment must happen **before numerical scoring**.

Do not use a scoring system to justify keeping a photograph that is visually weak.

Before formal evaluation, ask three questions:

1. **第一眼是否好看或具有足够强的视觉吸引力？**
2. **是否会让观看者愿意多停留几秒？**
3. **是否会产生保存、收藏或再次观看的欲望？**

If the overall answer is weak, reject the work before scoring.

Apply the following hard principle:

> **不好看 + 很特别 ≠ 好照片**

A photograph must not receive a high evaluation merely because it is:

- unusual;
- rare;
- strange;
- abstract;
- difficult to shoot;
- technically complex;
- conceptually unusual;
- visually confusing;
- shot in an exotic location.

Novelty is valuable only when it contributes to a strong photographic result.

---

# 4. Visual Appeal and Collectability

The final collection should maximize **visual collectability**.

A photograph has strong collectability when the viewer is likely to think:

- “这张我想保存。”
- “这张我还会再看。”
- “这张可以作为摄影或设计参考。”
- “这张单独拿出来也成立。”

High collectability often comes from one or more of the following:

- exceptional composition;
- excellent light;
- unusual but attractive color relationships;
- strong atmosphere;
- strong subject expression;
- meaningful visual tension;
- decisive timing;
- rare but aesthetically valuable behavior;
- surprising spatial relationships;
- excellent visual rhythm;
- memorable scale;
- powerful texture;
- controlled minimalism;
- elegant abstraction;
- visual storytelling;
- another difficult-to-substitute visual quality.

Collectability should be treated as a practical summary of overall aesthetic value.

# 6. Visual-Language Rotation

Long-term diversity should also occur at the visual-language level.

Rotate across contrasts such as:

- color / black-and-white;
- high saturation / restrained saturation;
- warm / cool;
- bright / low-key;
- monumental / intimate;
- macro / wide-scale;
- documentary / stylized;
- natural / artificial;
- human / non-human;
- static / dynamic;
- minimal / layered;
- soft / high-contrast;
- atmospheric / graphic;
- realistic / abstract.

Do not repeatedly default to:

- sunset landscapes;
- neon streets;
- mountains;
- oceans;
- golden-hour scenes;
- high-saturation images;
- cinematic landscape imagery.

These MAY be selected when they are genuinely strong, but must not dominate the long-term output simply because they are easy to make visually impressive.

# 7. Theme Selection Logic

Use the following priority:

1. explicit user request;
2. reliable recent-run history;
3. long-term category balance;
4. curatorial judgment;
5. search feasibility.

If the user specifies a theme, follow it.

If the user gives only a broad category, infer a stronger specific direction automatically.

Example:

User request:

> “帮我找动物照片”

Possible internal refinement:

> 动物行为 × 动态瞬间 × 环境肖像

Do not ask the user to choose an exact animal unless necessary.

If the user gives no theme, choose a theme that:

- has high visual potential;
- is not excessively repetitive relative to known history;
- can support a coherent 9-image series;
- allows strong photographic-language search terms;
- has enough credible real works available.

---

# 8. Search-Language Design

Do not search only with literal subject nouns.

Use photography-specific language to increase quality.

The preferred query structure is:

`subject + photographic language + visual characteristic + atmosphere/behavior/composition`

Examples:

## Landscape

Instead of:

`mountain`

prefer combinations such as:

- dramatic landscape photography;
- atmospheric perspective;
- storm light landscape;
- dramatic scale photography;
- mountain fog fine art photography;
- layered landscape composition;
- backlit landscape photography.

## Street / Documentary

Instead of:

`street people`

prefer:

- decisive moment street photography;
- layered street composition;
- documentary photography daily life;
- candid human interaction;
- visual storytelling street photography;
- environmental documentary photography;
- street photography reflection;
- urban gesture photography.

## Architecture

Instead of:

`building`

prefer:

- architectural abstraction;
- geometric architecture photography;
- light and shadow architecture;
- spatial rhythm photography;
- brutalist architectural photography;
- minimal architecture composition;
- urban color blocking photography.

## Wildlife

Instead of:

`animal`

prefer:

- wildlife behavior photography;
- decisive moment wildlife;
- environmental animal portrait;
- backlit wildlife photography;
- animal motion photography;
- wildlife interaction photography.

## Botanical

Instead of:

`flower`

prefer:

- fine art botanical photography;
- botanical macro;
- backlit flower photography;
- abstract botanical photography;
- plant texture photography;
- minimal floral photography.

## Portrait

Instead of:

`portrait`

prefer:

- environmental portrait photography;
- cinematic natural light portrait;
- expressive portrait photography;
- window light portrait;
- editorial portrait photography;
- monochrome emotional portrait.

## Industrial

Instead of:

`factory`

prefer:

- industrial documentary photography;
- machinery detail photography;
- worker industrial photography;
- sparks workshop photography;
- industrial geometry;
- factory light photography.

Search language should describe **how the photograph succeeds**, not merely what appears in it.

# 9. Initial Candidate Pool

For a full run with adequate search capability, build an initial candidate pool of approximately:

> **30–50+ photographs**

This is a target, not an excuse for unnecessary volume.

The purpose of the candidate pool is to create genuine competition.

Do not:

- stop after finding nine usable images;
- select the first nine search results;
- fill the pool with near-duplicates merely to reach a number;
- count obviously weak images as serious candidates.

The candidate pool SHOULD include meaningful competition from multiple searched platforms.

The pool MAY be larger when:

- the topic is broad;
- many strong works are available;
- the visual direction is still unclear;
- the first benchmark direction is weak.

The pool MAY be slightly smaller when:

- the topic is extremely narrow;
- strong licensed works are scarce;
- search-tool limitations prevent broader discovery.

Even then, do not claim that 30–50+ candidates were evaluated unless that actually occurred.

---

# 10. Initial Aesthetic Screening

Apply a fast but strict aesthetic screen to the candidate pool.

Reject photographs showing one or more of the following:

- generic stock-photo aesthetics;
- template-like composition;
- tourist-snapshot quality;
- weak visual center;
- unclear subject hierarchy;
- unintentional clutter;
- poor spatial organization;
- unattractive or uncontrolled color;
- excessive HDR;
- excessive sharpening;
- unnatural processing;
- low-value “pretty scenery only” aesthetics;
- weak emotional or visual presence;
- obvious AI-generation artifacts;
- highly replaceable visual treatment;
- weak timing;
- technically competent but visually forgettable results;
- novelty without aesthetic value.

Do not keep a photograph simply because:

- the location is famous;
- the animal is cute;
- the person is attractive;
- the building is famous;
- the weather is rare;
- the subject itself is inherently beautiful.

The photograph must succeed as photography.

---

# 11. Strong Candidate Pool

After initial screening, reduce the pool to approximately:

> **12–18 strong candidates**

These candidates should already be photographs that could reasonably enter the final collection.

At this stage, every candidate should satisfy:

- basic aesthetic appeal;
- clear photographic strength;
- clear visual center or visual logic;
- at least one meaningful memory point;
- reasonable fit with the emerging theme.

Do not waste formal scoring effort on obviously weak candidates.

---

# 12. Cross-Platform Comparison

Evaluate strong candidates together, regardless of source platform.

Do not reserve slots such as:

- 3 from Pexels;
- 2 from Unsplash;
- 2 from Flickr;
- 2 from elsewhere.

There are no final platform quotas.

For each strong candidate, ask:

1. **这张真的好看吗？**
2. **这张会让人愿意收藏吗？**
3. **它为什么应该挤掉另一张？**
4. **如果换成同关键词下的一张普通照片，这一组会明显变差吗？**
5. **它对整个系列提供了什么独特价值？**

If no strong answer exists, eliminate the candidate.

---

# 13. Irreplaceable Point

Every final work MUST have an **Irreplaceable Point**.

The Irreplaceable Point is the clearest reason the photograph deserves its place in the collection.

It should explain why replacing the photograph with an ordinary image would make the collection weaker.

Possible Irreplaceable Points include:

- unique composition;
- decisive moment;
- exceptional interaction;
- extraordinary lighting;
- rare atmospheric condition;
- unusual but elegant viewpoint;
- visually powerful scale relationship;
- subtle human gesture;
- rare animal behavior;
- unusual spatial layering;
- distinctive color relationship;
- extraordinary texture;
- visual coincidence;
- conceptual clarity;
- unusually strong emotional expression;
- exceptional abstraction;
- another high-value photographic quality.

The Irreplaceable Point must be specific.

Weak:

> “构图很好看。”

Better:

> “前景人物与后方列车在同一运动方向形成双层节奏，人物抬手的一瞬间又恰好与车窗反光重合，这种关系很难被普通街头照片替代。”

---

# 14. Creative Distinction / Visual Impact Gate

After basic aesthetic quality is established, each final photograph must satisfy at least one of two routes.

## Route A — Meaningful Creative Distinction

The photograph demonstrates meaningful photographic invention or distinction, such as:

- unusual viewpoint;
- effective visual misdirection;
- abstraction;
- decisive timing;
- unconventional framing;
- elegant asymmetry;
- unusual but controlled color;
- meaningful use of reflection;
- strong use of shadow;
- unexpected subject relationship;
- visual humor;
- visual coincidence;
- conceptual construction;
- another distinctive visual idea.

## Route B — Strong Immediate Visual Impact

The photograph produces strong first-impression impact through:

- extraordinary light;
- dramatic weather;
- exceptional color;
- striking scale;
- strong emotional expression;
- rare animal behavior;
- strong motion;
- unusual microstructure;
- exceptional spatial depth;
- powerful subject isolation;
- another memorable visual feature.

A photograph does not need to satisfy both routes.

However, it must already have passed the aesthetic-first gate.

---

# 15. Benchmark Image Selection

From the strongest candidates, select one **Benchmark Image**.

Do not choose the benchmark mechanically by score.

Ask:

> **如果这些照片只能留下1张，哪一张最舍不得删？**

The benchmark image SHOULD:

- have strong visual appeal;
- create strong collectability;
- remain compelling outside the context of the series;
- contain a clear visual direction that can support a 9-image collection;
- score approximately 92/100 or higher after formal evaluation.

The benchmark is the aesthetic anchor of the current collection.

---

# 16. Aesthetic DNA

Extract the benchmark's **Aesthetic DNA**.

Analyze the following dimensions:

## Composition

- central / off-center;
- symmetrical / asymmetrical;
- layered / minimal;
- diagonal movement;
- framing;
- leading lines;
- foreground-background relationships;
- subject placement;
- negative space.

## Visual Elements

- primary subject;
- secondary subject;
- environmental elements;
- repeated shapes;
- textures;
- structural elements.

## Color

- dominant hue;
- secondary hues;
- saturation;
- color contrast;
- complementary colors;
- analogous colors;
- monochrome tendency;
- warm/cool balance.

## Tone

- high-key;
- low-key;
- soft contrast;
- strong contrast;
- shadow density;
- highlight behavior.

## Light

- backlight;
- side light;
- soft light;
- hard light;
- diffuse light;
- window light;
- rim light;
- artificial light;
- mixed light.

## Subject

- subject type;
- subject scale;
- subject quantity;
- posture;
- movement;
- placement;
- relationship between subjects.

## Background

- detailed;
- minimal;
- environmental;
- blurred;
- graphic;
- atmospheric.

## Depth

- shallow depth of field;
- deep focus;
- layered depth;
- atmospheric perspective;
- flat graphic space.

## Material and Texture

- skin;
- fabric;
- metal;
- glass;
- water;
- dust;
- fur;
- feathers;
- foliage;
- concrete;
- smoke;
- other materials.

## Visual Rhythm

- repetition;
- movement;
- spacing;
- directional flow;
- density;
- pause points.

## Emotion

- quiet;
- loneliness;
- warmth;
- tension;
- grandeur;
- intimacy;
- mystery;
- joy;
- melancholy;
- energy;
- other emotional tone.

## Narrative

- implied story;
- human interaction;
- environmental context;
- decisive moment;
- unresolved visual narrative;
- symbolic relationship.

## Impact Source

Identify exactly what creates the strongest first impression.

## Creative Source

Identify exactly what makes the photograph distinct.

## Irreplaceability

Identify what would be difficult to reproduce with a generic substitute.

The Aesthetic DNA should be concise enough to guide search, but specific enough to distinguish the series.

---

# 17. Second-Round Search

After selecting the benchmark image, perform a second search round when search capability permits.

Search using combinations derived from the benchmark Aesthetic DNA.

Example:

Benchmark:

> 奔跑马群 + 暖色逆光 + 扬尘 + 中远景 + 群体运动 + 强方向性

Second-round search terms may include:

- running horses dust backlight photography;
- herd horses sunset dust;
- horse motion golden light;
- wild horses atmospheric photography;
- horse herd dynamic documentary photography.

Do not search only by exact visual duplication.

The second round should find photographs that reinforce the visual language while adding meaningful variation.

---

# 18. Coherence Without Duplication

The final collection must balance:

> **统一性 + 变化**

The photographs should feel related through one or more of:

- subject;
- color;
- light;
- composition;
- atmosphere;
- movement;
- visual rhythm;
- environment;
- narrative;
- photographic intent.

However, avoid excessive repetition.

Do not select nine photographs that are effectively:

- the same angle;
- the same pose;
- the same scene;
- the same lighting;
- the same composition;
- near-identical frames from one burst sequence.

A good series should feel consistent, not redundant.

---

# 19. Subject Consistency

If the benchmark image has a clearly dominant subject category, the final collection MUST preserve that subject category.

Examples:

- horse → horse imagery;
- butterfly → butterfly / closely compatible lepidoptera imagery;
- dancer → dancer imagery;
- architecture → architecture;
- flower macro → flower/botanical macro;
- bird → bird imagery.

If a more specific subject class becomes visually important, SHOULD preserve that more specific class.

Example:

If the benchmark is:

> wild horses running in dust

then a static studio horse portrait may be technically the same subject but may fail the collection's visual language.

Variation is allowed in:

- number of subjects;
- species or subtype where appropriate;
- posture;
- movement;
- location;
- weather;
- viewpoint;
- light;
- color;
- framing.

If nine sufficiently strong works cannot be found:

1. broaden valid search language;
2. search additional credible sources;
3. reconsider the benchmark;
4. select a stronger theme if necessary.

Do not lower the quality threshold merely to keep the original benchmark.

---

# 20. Creator and Series Consistency

Works from the same photographer or the same photographic project MAY receive additional preference when quality is comparable.

This can improve:

- visual consistency;
- color continuity;
- thematic coherence;
- narrative unity.

However, creator consistency is never more important than image quality.

Use this priority:

1. individual image quality;
2. Aesthetic-DNA fit;
3. subject consistency;
4. series coherence;
5. same creator / same project.

Nine excellent works from different photographers are preferable to nine uneven works from one photographer.

---

# 21. Formal Scoring System

Only score photographs that have already passed aesthetic screening.

Use a 100-point framework.

| Dimension | Points |
| --- | ---: |
| 构图与空间 | 20 |
| 光影 | 20 |
| 色彩与调色 | 15 |
| 视觉冲击与记忆点 | 25 |
| 氛围与叙事 | 10 |
| 技术与质感 | 10 |
| **总分** | **100** |

---

# 22. Composition & Spatial Design — 20 Points

Evaluate:

- visual hierarchy;
- balance;
- subject placement;
- framing;
- use of negative space;
- foreground/midground/background;
- leading lines;
- geometry;
- rhythm;
- spatial depth;
- cropping;
- tension;
- intentional asymmetry or symmetry.

High score:

- composition feels deliberate;
- subject relationships are clear;
- the eye moves naturally through the frame;
- spatial organization contributes meaningfully to the photograph.

Low score:

- accidental composition;
- visual clutter;
- weak hierarchy;
- poor cropping;
- dead space without purpose;
- awkward subject placement.

---

# 23. Light — 20 Points

Evaluate:

- direction;
- quality;
- intensity;
- highlight control;
- shadow detail;
- contrast;
- atmosphere;
- relationship between light and subject;
- whether the light contributes to the image's emotional or structural quality.

High score:

- light is a major visual asset;
- light defines form;
- light strengthens atmosphere;
- light produces memorable visual structure.

Low score:

- flat lighting without purpose;
- uncontrolled exposure;
- distracting highlights;
- lost subject detail;
- light that weakens the image.

General threshold:

> **Light <14/20 normally disqualifies a work.**

Exception:

A photograph with exceptional documentary truth, decisive timing, conceptual value, or another equally strong photographic quality may survive weaker conventional lighting if explicitly justified.

---

# 24. Color & Tonal Treatment — 15 Points

Evaluate:

- color harmony;
- saturation;
- hue relationships;
- tonal control;
- white balance;
- color hierarchy;
- monochrome quality where applicable;
- whether color contributes meaningfully to the image.

High score:

- color feels intentional;
- palette strengthens mood or structure;
- tonal relationships are refined;
- color is memorable without becoming artificial.

Low score:

- muddy color;
- uncontrolled saturation;
- inconsistent color;
- processing that feels artificial;
- weak tonal separation.

Black-and-white photography should be judged by tonal structure rather than absence of color.

---

# 25. Visual Impact & Memorability — 25 Points

This is the highest-weighted category.

Evaluate:

- first-impression strength;
- visual surprise;
- collectability;
- memorability;
- emotional impact;
- scale;
- subject expression;
- decisive timing;
- unusual relationships;
- difficult-to-substitute visual qualities.

General threshold:

> **Visual Impact & Memorability <18/25 normally disqualifies a work.**

A photograph may be technically excellent but still fail if it is forgettable.

A final work should provide a clear answer to:

> “为什么我会记住它？”

---

# 26. Atmosphere & Narrative — 10 Points

Evaluate:

- mood;
- emotional tone;
- implied narrative;
- human or subject relationships;
- sense of place;
- environmental context;
- ambiguity;
- storytelling;
- visual tension.

High score:

- photograph implies more than it literally shows;
- atmosphere is coherent and distinctive;
- viewer can sense an emotional or narrative world.

Low score:

- purely descriptive;
- emotionally flat;
- little sense of context or intention.

---

# 27. Technical Quality & Texture — 10 Points

Evaluate:

- focus;
- motion treatment;
- exposure;
- detail;
- dynamic range;
- texture;
- noise;
- processing;
- clarity;
- intentional technical imperfection.

Technical imperfection is not automatically negative.

Examples of valid imperfection:

- film grain;
- motion blur;
- high ISO;
- imperfect focus;
- flare;
- underexposure;
- blown highlights.

These may be acceptable when they contribute intentionally to the photographic expression.

---

# 28. Score Interpretation

Use the following guidance:

## 95–100

Exceptional.

The photograph would be worth actively recommending even outside the current collection.

It must have:

- obvious aesthetic strength;
- strong memorability;
- a clear Irreplaceable Point;
- very high photographic completion.

Do not give 95+ casually.

## 90–94

Excellent.

The photograph has at least one clearly exceptional dimension and remains highly collectable.

## 85–89

Strong.

Suitable for the final collection if it strengthens the series.

## 80–84

Good but potentially replaceable.

Usually keep only as a strong candidate, not a final selection.

## Below 80

Generally unsuitable for the final set.

---

# 29. Final Score Thresholds

Default expectations:

- Final works SHOULD score **85 or above**.
- Benchmark image SHOULD score **92 or above**.
- 90+ MUST have an identifiable reason.
- 95+ MUST be exceptional outside the current series.
- Visual Impact & Memorability SHOULD be at least **18/25**.
- Light SHOULD be at least **14/20**, subject to justified exceptions.

Do not use arithmetic alone to override the aesthetic-first rule.

A photograph that scores mathematically well but feels unattractive or uncollectable should still be rejected.

---

# 30. Quality Competition

The final nine should be chosen through direct competition.

Before retaining each photograph, ask:

- What does this photograph contribute?
- Is another candidate stronger in the same role?
- Does it add visual variety?
- Does it support the benchmark DNA?
- Is it too repetitive?
- Is it too replaceable?
- Would the series become weaker if this image were removed?

If the answer to the last question is “probably not,” reconsider the photograph.

---

# 31. Final Nine Composition

The final nine should collectively contain:

- one strong benchmark anchor;
- enough visual variation to maintain interest;
- clear thematic unity;
- multiple distinct visual memory points;
- no obvious filler.

Avoid:

- one excellent image + eight weaker supporting images;
- excessive near-duplicates;
- platform-driven selection;
- convenience-driven selection;
- retaining low-quality images to satisfy a count.

The ninth-best image should still be genuinely worth saving.

---

# 32. Final Pre-Verification Checklist

Before moving the final candidates into source verification, confirm:

## Individual Quality

- [ ] Every work passed aesthetic-intuition screening.
- [ ] Every work has real visual appeal.
- [ ] Every work has a clear memory point.
- [ ] Every work has an Irreplaceable Point.
- [ ] No work survives merely because it is unusual.
- [ ] No generic stock image remains.

## Series Quality

- [ ] One benchmark image has been selected.
- [ ] Benchmark Aesthetic DNA is clear.
- [ ] The collection has strong coherence.
- [ ] The collection avoids excessive duplication.
- [ ] Subject consistency is satisfied where applicable.
- [ ] The series includes meaningful visual variation.

## Selection Integrity

- [ ] Final selection was based on quality rather than platform quotas.
- [ ] Download convenience did not drive the selection.
- [ ] Same-creator preference did not override image quality.
- [ ] No weak image was retained merely to complete nine.

## Scoring

- [ ] Only strong candidates were formally scored.
- [ ] Scores reflect actual photographic quality.
- [ ] 90+ scores have explicit reasons.
- [ ] 95+ scores are genuinely exceptional.
- [ ] Numerical scoring did not override aesthetic judgment.

---

# 33. Final Curatorial Standard

Before handing the nine works to the source-verification stage, ask one final question:

> **如果这9张作为一组公开展示，我会不会觉得其中有任何一张明显是在凑数？**

If yes, continue searching or replace the weak work.
